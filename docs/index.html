ディスク台帳ビューア

ディスク台帳で書き出したCSVを開いて、ディスクの中身を確認・検索できます。

ディスク台帳の「保存 → CSVに書き出す」で作ったCSVを選んでください。
ここにドロップしても開けます(複数可)。

ファイルはこのブラウザの中だけで読み込まれます。サーバーなど外部には一切送信されません。ページを閉じると内容は消えます。

ソフト本体 (Windows用)
ディスクの中身を記録してCSVを書き出すソフトです。動かすには Python が必要です。
disk_daicho.pyw をダウンロード

ディスク台帳 (Disk-Daicho) のCSVを見るためのページです。
